# 難易度の統計レポート（ローグライク）

自動生成（`node tools/balance.js report`）。作成日: 2026-11-19（日本時間）

冒険を3種類の遊び方で、各 120 回ずつ地下100階まで自動で遊ばせた結果です。死んだら「この階をやり直す」で続けて、死んだ回数を数えています（広告での復活は使わない前提）。

- **上手**: よく探して、いつも一番よい線を選ぶ
- **ふつう**: よさそうな線を選ぶが、ときどき2番手・3番手を選ぶ（60% / 25% / 15%）
- **初心者**: あまり探さず迷いやすい（45% / 30% / 25%）。祝福もでたらめに選ぶ

## 目標（「ちょうどよく倒せる」の定義）

調整は「ふつう」の遊び方に合わせています。

1. **ふつうの敵**: 階段が出るまで、1ターンに **1.2体（第1章）→0.9体（第10章）** 倒せる。1階で5〜7体倒すので、階段まで5〜7ターン。うまく連撃をつなげば一気に進み、下手につなぐと剣が足りない
2. **ボス**: ふつうの一筆で **約4回**。さらにルールとして、ボスは **1ターンに最大HPの4割まで** しか削れない（どんなにうまい連撃でも最低3ターン）
3. **被ダメージ**: 1階で最大HPの **15%（第1章）→35%（第10章）**。深くなるほど守りが要る。ただし **1階で死ぬ率は1.5%まで**（超えたら敵の攻撃を下げる）。章が変わっても敵の一撃は1.35倍までしか重くしない
4. **章の中の波**: ボスを倒した直後はやさしめ（倒せる数×1.1・被ダメージ×0.8）、ボスの手前はきつめ（×0.9・×1.2）

最初は被ダメージ40%→65%で試しましたが、1階で死ぬ率が30%を超えて厳しすぎたため、上の値に下げています。

### 今のルール

- 線は何マスでもなぞれる（以前は8マスまで。そのころの目標は1ターンに0.85体→0.6体）
- **連撃**: 1本の線で倒すたびに剣の威力が ×1.25、×1.5…（最大×3）
- **地形**: 地下2階から岩が3〜7個。岩と岩のななめのすき間も通れない。バクダンの爆発で壊せる。どの1マスがふさがれても残りがつながる形だけを使う（敵が居座って先へ進めなくなる袋小路を作らない）
- **階段が出たあと**: なぞったマスには何もないマスが補充される（倒した敵のマスにはアイテムが落ちる）。居残って稼げないように
- **勇者の強さに合わせた敵**: 平均的な勇者（この自動プレイの中央値＝balance.js の expect）より {剣} が強ければ敵のHPを、最大HPが多ければ敵の攻撃を上げる（比の0.85乗・0.7乗）。さらに、目安より速く・あまり傷つかずに階を突破するたびに「手ごたえ」が上がり（最大で敵のHP×2・攻撃×1.5）、手間取ったりやられたりすると下がる。表の「敵の強さ補正」はその倍率
- **力をためる**: 勇者を2回タップすると1ターン使って次の線の{剣}が増える（となりの岩も砕ける）。鎧の敵とゴーストは盤面に2体まで
- ノルマは1階で5〜7体（以前は3〜5体）
- ボスは1ターンに最大HPの4割までしか削れない（連撃の勢いで一発で倒せてしまうことがあったため）

被ダメージの目標（15%→35%）より「1階で死ぬ率1.5%まで」を優先しています。線が長くなって敵の数も増えたぶん、平均の被ダメージが目標どおりでも、まとめて攻撃を受けて死ぬことが増えたためです。

「連撃率」は、敵を倒せたターンのうち2体以上まとめて倒せた割合です。
